# 相关工作：分类并定位贡献

来源：《如何写论文-Related Works.pdf》第 1-4 页。

## 组织方式

按研究方向或方法类别建立研究脉络，比较各路线的假设、解决的问题、优势与限制。

每段可按“方向概括 → 代表工作 → 共同特点 → 局限或与本文的关系”展开。同类工作合并讨论，对最接近本文的工作给出足够具体的比较。

引言中的文献用于建立问题动机；相关工作进一步说明技术路线和贡献位置。控制重复，优先解释与本文有关的差异。

## 准确描述关系

| 关系 | 可以说明的贡献 |
| --- | --- |
| Extension / 扩展 | 拓展到新场景、任务、数据或模型 |
| Complement / 互补 | 补充现有方法、评测或分析的其他方面 |
| Contrast / 差异 | 改变假设、任务定义、研究对象或评价目标 |
| Unification / 统一 | 用一个框架联系此前分散的问题或方法 |
| Re-evaluation / 重新评估 | 识别原有评价的遗漏或偏差，重新刻画已有方法 |

客观承认已有贡献，并用其真实内容支持局限判断。引用数量服务于覆盖关键路线和支撑主张。

## 对比表

需要同时比较多项工作时，用领域合理且与核心问题相关的维度组织表格，例如假设、任务、数据规模、覆盖范围、模态、评价方式或成本。

各行采用一致标准；无法从来源判断的信息标为未知或未报告，并解释符号。核对最接近工作的覆盖情况，避免通过偏置的特征选择制造差异。
