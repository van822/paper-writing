# 实验：使证据回应贡献

来源：《如何写论文-Experiments.pdf》第 1-4 页，并结合摘要指南第 2 页的问题与结果对应原则。

## 按贡献组织实验

| 内容 | 要回答的问题 |
| --- | --- |
| Experimental Setup | 在什么条件下得到结果，比较是否公平？ |
| Main Results | 整体表现如何，哪些结果支持主要贡献？ |
| Ablation Study | 关键模块或设计带来了什么贡献？ |
| Analysis / Further Study | 为什么出现该行为，在哪些条件下表现不同？ |
| Case Study / Visualization | 具体输出、行为差异、任务难度或失败是什么？ |
| Robustness / Generalization | 在哪些干扰或变化下仍然有效？ |
| Efficiency / Cost | 性能改善对应什么时间、计算或其他成本？ |

根据论文主张选择必要内容。对每项主要贡献安排有针对性的证据，并说明验证条件。

## 实验设置

交代数据集与 benchmark、基线、评价指标、实现细节、训练或运行参数、重复次数、随机种子及统计方法。清楚说明各方法的比较条件，详细配置可放附录。

写作中采用已有实验的实际记录。统计信息缺失时说明待补项，保持证据来源可追溯。

## 结果叙述

明确引导读者查看对应图表，指出关键现象和数值，再解释其意义及与研究问题的联系。主表中的优势、提升较小和未提升的情况都纳入准确判断。

叙述重点由贡献决定。避免机械复述全部单元格，优先解释最关键、典型或能揭示机制与边界的结果。

## 消融与进一步分析

消融围绕设计动机，采用删除、替换、目标或策略变更等方式比较关键设计与完整方法。交代具体改变及其他条件，避免把伴随的配置差异归因于单一模块。

进一步分析可包括样本类别、任务难度、数据或模型规模、错误类型、超参数敏感性、专家一致性等。选择能解释方法行为的分析，说明适用条件与不足。

案例兼顾有代表性的成功与失败，用于解释数字难以完整呈现的现象，并控制由少量案例推广结论的范围。

## 异常与不确定性

如实报告异常、不符合预期及未提升的结果，说明其发生条件和对结论的影响。原文建议使用缓和措辞；在实际写作中，“轻微”“可忽略”“不显著”等判断需要相应证据。

误差条、阴影带和“均值 ± 数值”须说明统计含义与样本或重复次数。统计显著性、实际效应大小及结果波动分别解释。
